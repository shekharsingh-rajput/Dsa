# AKTU Data Structures and Algorithms (DSA) Roadmap

A structured learning roadmap for completing the **AKTU B.Tech CSE Data
Structures and Algorithms syllabus** using **C**. It covers all five
units, provides a topic tree, and gives a practical study checklist.

## Goals

-   Complete all five syllabus units.
-   Understand each data structure and algorithm.
-   Implement core topics in C.
-   Practise dry runs, complexity analysis, and AKTU-style questions.
-   Revise with a topic-by-topic checklist.

## How to Study Each Topic

For every algorithm or data structure:

1.  **Understand:** Write a short explanation of what it does and when
    it is used.
2.  **Dry-run:** Trace a small example by hand.
3.  **Implement:** Write and test the C program yourself.
4.  **Analyse:** Record time complexity, space complexity, and important
    edge cases.
5.  **Practise:** Solve theory questions and AKTU-style problems.

## Recommended Order

1.  C prerequisites
2.  Complexity and algorithm analysis
3.  Arrays and linked lists
4.  Stacks, queues and recursion
5.  Searching, hashing and sorting
6.  Trees, BST and traversals
7.  AVL trees, B-trees, heaps and Huffman coding
8.  Graphs, BFS/DFS, MST and shortest paths
9.  Previous-year questions and full revision

## Notes

-   Use C for implementations because it reinforces pointers and memory
    representation.
-   The syllabus is the priority. Interview topics outside the listed
    syllabus can come later.
-   Check your university's latest syllabus and faculty instructions for
    exact terminology and exam emphasis.
-   This roadmap is a study guide, not a guarantee of exam questions.
